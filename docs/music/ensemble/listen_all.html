Ensemble recordings

Not yet listened to by anyone. MT-2 (C-92) recorded every song the game plays in the Ensemble treatment. The two pilots (Snowbell, the Keepers' Road battle) were heard by Robin on 2026-10-12 (their captures). The others were made the same way, with each part's balance set by measurement against the Original and voices chosen by the lead for the instruments the pilots did not use; nobody has heard them yet. What each is made of is listed under it.

Each song's player is its full track: the recording as the game plays it, from the cue's start through the whole first pass and five seconds on into its repeat (a cue that does not loop: the whole of it), rendered by the game's own code through its own audio graph at the default volumes and the song's trim. In the game the repeat goes on for as long as the cue lasts. Under it are the recording's own files in both formats, as the game fetches them (Ogg Opus first; MP3 for a browser without Opus). Both are the same Ensemble recording. Measurements: docs/music/ensemble/qa/<song>.json.
