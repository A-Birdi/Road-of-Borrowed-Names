# Words: kept sentences and Creatures met (addendum §20)

These are captures of the built game in headless Chromium, made by
`node tests/e2e/bookmarks.mjs`. The PNGs are written to `tests/e2e/out/words/`;
the WebPs here are those PNGs at half size. The test states are synthetic:
new campaigns, a test scene, and real battles. They show what the test
exercised. They are not a playthrough.
