### APIs

`RB.pages` (src/content/pages/10_pages.js):
- `state(s)` — the committed companion's project or `null`.
- `pending(s, where?)` — the conversation waiting here: `{ id, scene, en }` with
  id `retro | unfinished | offer | home2 | home3 | road`, or `null`. `where` is
  `'hall'` (rw.hall), `'safe'` (any other non-Atlas map) or `'atlas'`. **For
  worker C1:** the Company page's "Ask what's on their mind" can show `en` and
  run `scene` (through its safe-state rule); nothing else is needed.
- `capture(s, ev)`, `runEnded(s, ev)` — also driven by the bus events below.
- Commits: `accept(s, theme)`, `page2(s, aspect, 'camp'|'home')`, `page3(s, captionIndex)`,
  `endingDone(s, retro)`, `unfinishedDone(s)` — each returns `false` when not
  eligible; awards go through `RB.company.award` only.
- Predicates: `needRetro`, `needUnfinished`, `offerOpen`, `returned`, `retOf`,
  `campOpen`, `home2Open`, `home3Open`, `roadCampOpen`, `roadHomeOpen`,
  `recallable(s)` (the shared memory an ending would recall), `petVisible`, `pqDone`.
- Data: `PROJECT`, `REPLY`, `RET`, `MEMO_TITLE`, `TOPICS`, `SHOW`, `MEM`, `drawArt(which, canvas|ctx)`.

Bus events emitted by `src/atlas/50_run.js`:
`atlas:event { run, id, kind: inscription|lanterns|sign|promise|name|doors|guardian|climax, room, pattern, branch, name?, boss?, read?, assisted? }`,
`atlas:camp { run, room }`, `atlas:end { run, kind: complete|early|defeat|abandon }`.

Condition heads (for scenes): `pages.retro|unfinished|offer|camp|home2|home3|empty|roadcamp|roadhome|done|recall|retrotalk|fresh|settled|evpet`,
`pages.stage>=n`, `pages.theme=`, `pages.aspect=`, `pages.caption=`, `pages.ret=`, `pages.where=`, `pages.pick=`, `pages.at=camp|home`,
`pages.reply=`, `pages.completed>=n`, `pages.keeps>=n`; `petvis`, `petvis=cat` (an active pet shown in the world: `RB.pets.visible(s, 'world')`).

Hooks: `pages_choose theme|aspect|caption|reply [camp|home]`, `pages_event camp|home`,
`pages_recall`, `pages_end_done [retro]`, `pages_retro_begin`, `pages_unfinished_done`,
`pages_topic camp|home`, `pages_display`.

`RB.game.companionTalk` is wrapped once: when `pending(s)` has something for this
place, talking to your companion plays it; otherwise the original banter runs.

### Saved state

- `s.company.project = { v, comp, stage 1..3, theme, t1..t3, ev, aspect, where, caption, lastEmpty, road }`
  - `ev = { run, id, kind, desc{jp,en}, title{jp,en}, room, branch, mods[], pet{species,name}|null, t, ret }` —
    run identity, event identity, a safe readable description, the route (modifiers,
    branch), the return type and the pet present: copied into campaign data the
    moment the event happens, so the Atlas cleanup cannot lose it. The run keeps
    only `run.pages = { ev: id }`.
  - `ret`: `complete | early | defeat | folded` (a run that vanished without an
    `atlas:end`, e.g. an unrestorable save, is treated as *folded*, lazily).
  - `road = { camp, home, lastEnd, lastKind, recent[4], quiet }` — topic bookkeeping.
- `s.company.talk['road:<c>.<slot>'] = { t, variant, variants[] }`.
- Memories (Reflections): `ending:<c>` or `ending_retro:<c>` (with `pq`, `replyId`,
  `reply`, `retro`, `petSeen`), `unfinished:<c>`, `pages:1`, `pages:2`, `pages:3`.
- Bond (via `RB.company.award`): `ending` +2, `project:1`, `project:2`, `project:3` +1 each.
- Keepsakes (via `RB.discovery.keepsake`): `pages_nao | pages_mio | pages_ren | pages_suzu`,
  registered in `RB.content.keepsakes` with `category: 'shared', comp`.
- No migration was needed: everything is optional and derived lazily; an older
  postgame save is recognised by `postgame` + a committed companion + no ending memory.

## How it plays

| Suzu | "And everyone went on living." | `end.suzu.a`: off the stage edge, "without a costume", recognition, Hiro's truth, the sincere line | `end.suzu.b`: reply, the next act → the ribbon (original) → `end.suzu.c`: the ledger line "to be returned: next act. Without fail." (keeps her precision), pet, commit |

- **Recognition**: `pages_recall` names one real recorded memory of this companion
  by its title (discoveries > together > reflections > pets, most recent), with a
  per-companion line for its kind; with none, a verified main-journey reference
  (Lanternfall's bell, the Archive, Snowbell's blizzard, the Cinder Orchard workshop).
- **Personal quest**: Nao (`lf_nao` done / met Umi / never met), Mio (`lf_mio`
  done / pending at stage 2 / never started because the bell rang first), Ren
  (always decided at the Memories shelf: took / left — the original lines already
  acknowledge it), Suzu (`co_suzu` is required for Chapter 3). Open quests get an
  open-ended line that spoils no answer.
- **Reply**: three options per companion — two sincere, one quiet; each answered
  in character; none scored; recorded in the memory only.
- **Pet beat**: only when `RB.pets.visible(s, 'world')`; 16 authored lines
  (4 companions × 4 species), setting-neutral so they also fit the Hall. A pet's
  player-given name is never put into lines.
- **Commit**: `pages_end_done` → `RB.company.award(s, 'ending', 2)` and one Reflections
  memory, once. Replaying the scene (or a recollection) awards nothing.

- Page I: offered once on entering the Lantern Hall on a later visit — not in the
  visit the story ends on, where Tsuru introduces the Atlas (`pages.settled`), so
  nothing is stacked onto the ending; *Not now* keeps it; talking to the companion
  in the Hall opens it at any time. Never in front of `rw.atlas_go`.
- Page II evidence: the first `atlas:event` of an outing after Page I (restored
  inscription/sign/promise/lanterns, answered name, right door — described as
  "found" when the tablet was not read — settled guardian or climax). Assisted
  answers qualify. The threshold gate's inscription is the reliable first event.
- Page II talk: at the camp of that outing (menu option), or put off → at home.
- Page III: after any return from that outing — early (a real decision), complete,
  defeat (told as the road sending you home), folded. Offered at the homecoming
  (end of `atlas.home`) with *Later*; then by talking to the companion in the Hall.
- Empty outing (no event: e.g. defeated at the gate): one honest line at the
  homecoming, the project stays open, nothing is awarded or lost.
- Visible: the card on the wall (look at it: caption, the moment, a line), the
  Journey page (three pages, the recorded moment with route, return and pet, the
  memento art, where it hangs), the Company panel (whoever draws the Companion
  page; composed, not replaced).

### Talk about this road (§11.6)

12 topics per companion (h1–h4 habits, r1–r4 reflections on what you actually
shared, o1–o4 observations: pet / Reedwake's restorations / keepsakes / the place
you are). Each slot's lines are conditioned on the facts (pet shown or not, a road
walked to its end or not, `atlas_restore_1`, roadside keepsakes or not, camp or
Hall, the personal quest's state, the recorded ending reply), so every slot has
true content in every state. After Page III: one at the camp (menu option), one
after each homecoming (talk to the companion in the Hall). Unheard topics first;
a slot comes back only when its fact changed (e.g. a pet joined), never within
the last four; when nothing new is left, one of three brief ordinary lines. No
bond, reward or counter.
