# Expansion consultation transcript package

Start with `Road_of_Borrowed_Names_Expansion_Consultation_Transcript.html` for a formatted, self-contained reading copy, or the `.md` file to give Claude the chronological conversation as text. The `.txt` version preserves the same message content and original Markdown syntax in a plain-text container.

This is a historical discussion record, NOT a new implementation directive. No game source has been modified and no new feature scope is authorized by this package.

## Exact scope

Begins: Robin's "It's not yet down the pipeline until I'm satisfied with a full playthrough..." expansion consultation.

Ends: the assistant's reply to Robin's ten-point clarification, including the F/Ren testing approach and late final art pass, before the conversation returns to Harmony asset work.

Includes all nine substantive text entries in that span, including the two-entry Harmony interlude and the complete attached written review. The original review file is preserved byte-for-byte in `attachments/Expansion_Consultation_Review_original.txt`. The interlude screenshot is also preserved; no video or generated-image outputs are included. Referenced historical art files and the game build are not bundled.

The transcript is assembled from the visible conversation and the attached review, not a native ChatGPT account export. Line endings, trailing spaces, and the escaped pasted Markdown have been normalized. Message wording is not summarized or updated. Editorial notes, entry headings, and the index are clearly separated from the message text. Original source markers and external links are historical and have not been reverified.

`MANIFEST.sha256` checks the files in this package. It verifies packaging integrity, not the factual accuracy of historical claims or an independent byte-for-byte comparison to an unavailable account export.
