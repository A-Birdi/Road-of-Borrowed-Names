# Start here — single-model production handoff, v1.2

This package proposes how to deliver the complete expansion and art. It does not itself authorize repository changes. Robin must name the authorized scope and any accepted amendments first. The source draft remains unchanged in `source/`. This delivery is split into two ordinary ZIPs, each below 30,000,000 bytes. Upload both to Claude, or extract both into the same parent folder; their shared `RBN_Expansion_Playbook_v1_2/` directory forms one complete package. No split-archive utility is required.

**New font approved:** Robin permits a new font provided it is readable and stylized for the game's tone. UI-TYPE-01 is no longer an unresolved policy decision. The exact family still needs selection, licence/provenance verification, offline embedding, and English/Japanese/furigana readability checks. No font files are supplied in this package. See `source/Robin_Font_Approval.md` and `registers/latest_decisions.json`.
