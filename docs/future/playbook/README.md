# Expansion playbook v1.2 (Robin's package of 2026-10-09)

Robin supplied this package on 2026-10-09 as two ZIPs ("Part 1 of 2", "Part 2 of 2"), prepared with another
assistant from the expansion plan, draft 7 ([../plan/](../plan/)). It proposes how to deliver the whole expansion
and its art: a P00–P18 delivery sequence, the authored-book interface direction (§15A), sixteen discrepancies found
in draft 7 (D01–D16), a 118-feature execution register and twenty UI acceptance checks (UI-A01–UI-A20).

**It does not authorise any work by itself.** Its own words: "This package proposes how to deliver the complete
expansion and art. It does not itself authorize repository changes. Robin must name the authorized scope and any
accepted amendments first." The decisions it records (C-72, C-73 and C-74 approved; the new-font permission) are
carried into the plan, draft 8 ([../plan/11_CONTRADICTIONS.md](../plan/11_CONTRADICTIONS.md)).

## What is here, and what was changed on the way in

- **Text** (the playbook in Markdown, the UI addendum, START_HERE, revision notes, registers, templates, Robin's two
  decision records, and the draft-7 snapshot it was written from): kept as supplied, with two kinds of edit only.
  - **Names of AI models are replaced with neutral words** ("single-model", "another model", "a mixed-model plan
    mode"), because the project keeps model names out of committed files. The meaning is unchanged: one
    implementation model writes; no second model writes in parallel. File names that carried a model name were
    renamed (for example `EXPANSION_PLAYBOOK.md`, `templates/CONTINUATION_PROMPT.md`), and references to them follow.
  - **Image references point at `.webp`** copies (below).
- **Images:** the ten concept plates (`mockups/`) and Robin's two Journey/Company screenshots (`references/`) are
  WebP copies at quality 0.82, same pixel sizes, made with the project's Chromium. They are **references only**: not
  production assets, not part of the game, and not proof that anything was implemented (the playbook says the same).
- **Left out:** the two PDFs (the playbook, about 18 MB, and the visual atlas, about 17 MB) and the playbook's HTML
  rendering. They duplicate the Markdown and the images. `PARTS_MANIFEST.json` lists every original file's size and
  SHA-256, so Robin's copies can be matched exactly.
