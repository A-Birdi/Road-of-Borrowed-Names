# Revision 1.2 — font permission and two-part delivery

Robin permits a new font provided it is readable and stylized for the game's tone. This replaces the earlier no-new-font-files rule for that purpose only. No typeface has been selected, tested or included in this handoff; offline operation, no remote dependencies, language readability and the established visual review still apply.

The operative playbook PDF/HTML/Markdown, standalone UI addendum, START_HERE, continuation prompt, acceptance template, approval record and UI acceptance register have been updated. C-72, C-73 and C-74 remain approved as asked.

The expansion source, all original image references and the visual inspection atlas are retained without changing their source bytes. Historical v1.1 change records describe that earlier revision; this later approval takes precedence. No game implementation or tests were performed.

Delivery uses two independently readable ZIPs. Extract both into the same parent folder, or provide both to Claude. PARTS_MANIFEST.json lists each payload member's size, SHA-256 and part. Each ZIP is below 30,000,000 bytes. No original file is cut into binary fragments, omitted or downsampled.
